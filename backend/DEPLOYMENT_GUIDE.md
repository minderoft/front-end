## 🚀 Configuration pour Render.com (recommandé)

### Étape 1 : Préparer le repository GitHub
```bash
git add .
git commit -m "Préparation pour la production"
git push origin main
```

### Étape 2 : Créer un service sur Render

1. Accédez à [render.com](https://render.com)
2. Cliquez sur "New +" → "Web Service"
3. Connectez votre repository GitHub

**Configuration de base :**
- **Name** : `locaplus-api`
- **Environment** : `Node`
- **Region** : Choisir selon votre localisation
- **Branch** : `main`
- **Build Command** : `npm install`
- **Start Command** : `npm start`

### Étape 3 : Configurer les variables d'environnement

Dans Render, aller à **Settings → Environment** et ajouter :

```
NODE_ENV=production
PORT=3000

FRONTEND_URL=https://YOUR_FRONTEND_DOMAIN.com
JWT_SECRET=your_super_secret_key_minimum_32_characters

PAYSTACK_SECRET_KEY=sk_live_your_actual_live_key
PAYSTACK_PUBLIC_KEY=pk_live_your_actual_live_key

DATABASE_URL=sqlite://./database.sqlite
```

### Étape 4 : Déployer

Cliquez sur "Deploy" et attendez que Render configure le service.

**URL du serveur** :
```
https://locaplus-api.onrender.com
```

```

JWT_SECRET=<generate-strong-key>
PAYSTACK_SECRET_KEY=sk_live_xxx
PAYSTACK_PUBLIC_KEY=pk_live_xxx
```

**Générer JWT_SECRET sécurisé** :
```bash
node -e "console.log(require('crypto').randomBytes(64).toString('hex'))"
```

## 🔒 Sécurité Avant Déploiement

### 1. **JAMAIS commit `.env` avec vraies clés**
```bash
# .gitignore doit contenir :
.env
.env.local
.env.*.local
```

### 2. **Vérifier le `.gitignore`**
```bash
node_modules/
.env
.env.local
database.sqlite
uploads/*
!uploads/.gitkeep
dist/
build/
.DS_Store
```

### 3. **JWT_SECRET**
- Minimum 32 caractères
- Unique par environnement
- Stocké uniquement en variables d'environnement

### 4. **PAYSTACK Keys**
- Utiliser clés de TEST en développement
- Utiliser clés LIVE en production uniquement
- Ne jamais partager les clés

## 🛠️ Troubleshooting Courant

### "Port already in use"
**Solution** : La plateforme cloud assigne automatiquement le port via `process.env.PORT`

### "Cannot find module"
**Solution** : 
```bash
npm install
npm ci # À la place de npm install en production
```

### "CORS error"
**Solution** : Vérifier `FRONTEND_URL` dans les variables d'environnement

### "Database locked" (SQLite)
**Solution** : SQLite en production peut avoir des problèmes de concurrence.
- Option 1 : Utiliser PostgreSQL/MySQL en production
- Option 2 : Augmenter les timeouts SQLite

### "Out of memory"
**Solution** : Vérifier les limites de fichiers uploadés (10MB défini)
